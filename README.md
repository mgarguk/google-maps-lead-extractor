# Google Maps B2B Lead Extractor & Phone/Website Scraper 🚀

Extract high-quality local business leads directly into CSV and JSON format for sales outreach, marketing campaigns, and market research.

## Features
- **Extracted Data Fields:**
  - Business Name
  - Phone Number
  - Website URL
  - Rating & Review Count
  - Full Address Snippet
- **Export Formats:** CSV, JSON, Excel, XML.
- **Fast & Reliable:** Lightweight, proxy-friendly execution.

## Input Parameters
- `searchQuery`: Target keyword and location (e.g. `Dentists in Chicago`, `Real Estate Brokers in Miami`).
- `maxResults`: Maximum number of leads to extract (default: `50`).

## Usage
Simply click **Start**, enter your search query, and download your clean lead dataset!
